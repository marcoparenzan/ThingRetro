# roms

Put the system ROMs here (not versioned: copyrighted). Run `tools/Install-Roms.ps1` to copy them from C64 Forever.

| File | Content |
| --- | --- |
| `c-65-19910828.rom` | C65 system ROM (128 KB), BASIC 10 |
| `kernal`, `basic`, `chargen` | C64 ROMs, used by the old C64 board and its tests |
| `c-drive-1541.rom` | 1541 DOS (16 KB), for the external drive (Thing1500) |
