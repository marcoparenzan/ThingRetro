# roms

Put the system ROMs here (not versioned: copyrighted). Run `tools/Install-Roms.ps1` to copy them from C64 Forever.

| File | Content |
| --- | --- |
| `kernal` | C64 KERNAL (8 KB) |
| `basic` | C64 BASIC V2 (8 KB) |
| `chargen` | C64 character generator (4 KB) |
| `c-drive-1541.rom` | 1541 DOS (16 KB), for the 1541 drive (ThingCommodore) |
| `c-drive-1581.rom` | 1581 DOS (32 KB), for the 1581 drive (ThingCommodore) |
